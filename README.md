## Примеры кода

### Создание интерактивной анкеты студента

```csharp
using System;

Console.WriteLine("Добро пожаловать в анкету!");

// Ввод данных
Console.Write("Введите ваше имя: ");
string name = Console.ReadLine() ?? "";

Console.Write("Введите вашу фамилию: ");
string surname = Console.ReadLine() ?? "";

Console.Write("Введите вашу группу: ");
string group = Console.ReadLine() ?? "";

Console.Write("Введите ваш год рождения: ");
int birthYear = int.Parse(Console.ReadLine() ?? "0");

Console.Write("Введите ваш средний балл (например, 4.5): ");
double gpa = double.Parse(Console.ReadLine() ?? "0");

// Вычисления
int currentYear = 2026;
int age = currentYear - birthYear;
bool isExcellent = gpa >= 4.5;
string status = isExcellent ? "Отличник" : "Хорошист";

// Вывод результата
Console.WriteLine("\nВаша анкета:");
Console.WriteLine($"Имя:           {name} {surname}");
Console.WriteLine($"Группа:        {group}");
Console.WriteLine($"Возраст:       {age} лет");
Console.WriteLine($"Средний балл:  {gpa}");
Console.WriteLine($"Статус:        {status}");
Console.WriteLine($"Лет до 30:     {30 - age}");

```


## Главные выводы

1. C# является строго типизированным языком программирования, где тип переменной определяется при компиляции, что повышает надёжность кода по сравнению с динамически типизированными языками.
2. Платформа .NET предоставляет удобный консольный интерфейс (CLI) `dotnet run`, позволяющий быстро компилировать и запускать приложения без использования тяжеловесных IDE.
3. Особенность деления целых чисел в C# заключается в отбрасывании дробной части; для получения точного дробного результата хотя бы один из операндов должен иметь тип `double` или `float`.

## Ответы на вопросы

1. `Console.Write()` выводит текст в консоль и оставляет курсор на той же строке, а `Console.WriteLine()` после вывода текста автоматически переносит курсор на новую строку.
2. Возникнет ошибка компиляции `CS0266` ("Невозможно неявно преобразовать тип double в int"), так как C# запрещает сужающие преобразования с потерей точности без явного приведения типов.
3. При делении двух целых чисел (`int`) C# выполняет целочисленное деление, отбрасывая дробную часть. Чтобы получить дробный результат, хотя бы один из операндов должен быть дробным типом: `10.0 / 3` или `(double)10 / 3`.
4. Ключевое слово `var` включает неявную статическую типизацию: компилятор сам определяет тип переменной на этапе компиляции по присваиваемому значению. В отличие от Python, где тип переменной динамический и может меняться во время выполнения, в C# тип переменной, объявленной через `var`, фиксируется навсегда.
5. Microsoft: разработка сервисов Azure, компонентов ОС Windows и пакета MS Office.
* Stack Overflow: вся серверная логика и бэкенд платформы работают на .NET / C#.
* Игровая индустрия (Unity): движок Unity использует C# как основной язык для разработки игр (Genshin Impact, Cuphead, Subnautica).
